# CF-GNNExplainer — Minimal Counterfactual Edits Are Dependency Witnesses

**Paper:** arXiv:2102.03322  
**Title:** CF-GNNExplainer: Counterfactual Explanations for Graph Neural Networks  
**Authors:** Ana Lucic, Maartje ter Hoeve, Gabriele Tolomei, Maarten de Rijke, Fabrizio Silvestri  
**Source:** https://arxiv.org/abs/2102.03322  
**PDF:** https://arxiv.org/pdf/2102.03322

## Punchline

> **Search for the smallest graph perturbation that changes the prediction. Minimality turns a destructive edit into a compact dependency witness.**

CF-GNNExplainer generates counterfactual explanations by finding minimal perturbations to graph input that change a GNN prediction. The original method restricts its perturbations to edge deletion.

---

## What the paper actually establishes

The method optimizes for a counterfactual graph close to the original graph but with a different model prediction.

Conceptually:

    minimize distance(G, G')
    subject to
    prediction(G') != prediction(G)

The paper reports that on three common GNN explanation datasets it can generate counterfactuals for most instances while removing fewer than three edges on average.

The substrate-relevant idea is the explicit search for a minimal decision-changing edit.

# Harvest for lance-graph

## H1 — Ablation should return a witness, not only a delta

Instead of merely saying:

    candidate removal changed the score

prefer to preserve:

    which edge/path/evidence mask was minimally sufficient to change the verdict?

That witness can be replayed and falsified.

## H2 — Virtual masks fit the architecture

No copied graph is required if the fold can consume:

    base generation
    +
    counterfactual mask

and execute the same program.

This is precisely the kind of fold-first, materialize-last workload the substrate wants.

## H3 — Minimality reduces collateral explanations

Deleting a central hub may break everything.

A smaller edit that flips only the target verdict is a better diagnostic of the relevant dependency.

---

# Testables

## T1 — One critical edge among distractors

The counterfactual search should recover the critical edge without deleting unrelated structure.

## T2 — Redundant paths

Two interchangeable routes should require a multi-edit counterfactual.

A one-edge deletion that leaves the verdict unchanged must not be mislabeled a failure of causal relevance.

## T3 — Mask/materialization equivalence

Run the same counterfactual via:

1. copied graph with the edge removed;
2. immutable graph plus exclusion mask.

The result must agree exactly for deterministic folds.

## T4 — Minimality

If one edit flips the verdict, an explanation with three edits should lose unless another declared objective justifies the extra edits.

---

## Guardrail

CF-GNNExplainer explains the decision boundary of a model.

A minimal counterfactual edit is therefore a **model-dependency witness**, not automatically a real-world cause.
