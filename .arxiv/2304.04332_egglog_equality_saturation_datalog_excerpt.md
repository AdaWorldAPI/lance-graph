# egglog: share equivalent expressions, then extract a checked relational program

**Source:** Yihong Zhang et al., *Better Together: Unifying Datalog and Equality Saturation*, [arXiv:2304.04332v4](https://arxiv.org/abs/2304.04332), [HTML](https://arxiv.org/html/2304.04332v4); revised 2023-05-15. §§1–5 and appendices on equation solving/matrices.  
**Implementation source:** [egraphs-good/egglog](https://github.com/egraphs-good/egglog), [3.0 proof documentation](https://egraphs-good.github.io/egglog/docs/egglog/proof/index.html). **Research status:** primary-source and API reading, not library integration.

## Source-grounded excerpt

egglog combines Datalog's incremental / semi-naive rule processing with equality saturation's **congruence closure**, term rewriting and extraction. Extensional relational facts, functional dependencies and equality classes must be modeled distinctly. The paper demonstrates pointer-analysis and floating-point rewrite applications. It does not assert that every Datalog join or side-effecting program admits an equality-preserving Boolean rewrite.

Current egglog 3.0 has a read-only **proof reconstruction** API. Its `ProofStore` is a hash-consed arena sharing subproofs via `ProofId`; proofs justify *equality propositions between terms*. That alone is not a proof that a physical Lance write succeeded.

## Hypothetical transfer

Cold, version-pinned optimizer outside the hot mask-RISC path:
`relalg/R2IL terms -> sorted/canonicalized predicates -> e-class saturation -> extract minimal witnessed DAG -> palette8 opcodes -> QR256 folds`.

Metric should combine bindings, source reads, mask materializations, dirty propagation and replay cost. A shorter AST can perform worse if extraction destroys co-addressing or induces repeated preparation.

Small motivating equality: `a = 2*b; b = 2*c; z = 2*a`, hence `z = 8*c` under exact integer arithmetic. Under saturating u8 arithmetic or f64 reassociation this needs a separate law or a refusal. Cyclic equations require conflict/termination handling; avoid unbounded saturation.

## Falsifiers / test path E

- **E1, substitution:** Prove `z == 8*c` with exact integer constants and capture a replayable DAG. Remove a premise; the proof must fail or be incomplete.
- **E2, million requested applications:** 256 templates × 4,096 focus contexts = 1,048,576 applications. Measure input program records, shared e-nodes/e-classes, extracted program op count, certificate bytes, planner time, memory, validation time, and end-to-end execution. Compare against an intentionally nonsharing workload; no universal small-certificate promise.
- **E3, typed laws:** Existential `OR` versus parity `XOR` and set versus bag COUNT must not unify. Duplicate derivations give a mandatory counterexample.
- **E4, proof/witness:** Check extracted expression equivalence and separately validate BEFORE/AFTER by independent QR scalar oracle; stale coordinate/palette generation refuses.
- **E5, termination:** Recursive cyclic term rules obey fuel/node limits; no infinite expansion; compare bound-limited saturation to ordinary relalg normalization.
- **Silence twin:** An algebraically redundant rewrite changes neither result nor committed dirty bit.
