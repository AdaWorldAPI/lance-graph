# egglog: share equivalent expressions, then extract a checked relational program

**Source:** Yihong Zhang et al., *Better Together: Unifying Datalog and Equality Saturation*, [arXiv:2304.04332v4](https://arxiv.org/abs/2304.04332), [HTML](https://arxiv.org/html/2304.04332v4); revised 2023-05-15. §§1–5 and appendices on equation solving/matrices.  
**Implementation source:** [egraphs-good/egglog](https://github.com/egraphs-good/egglog), [3.0 proof documentation](https://egraphs-good.github.io/egglog/docs/egglog/proof/index.html). **Research status:** primary-source and API reading, not library integration.

## Source-grounded excerpt

egglog combines Datalog's incremental / semi-naive rule processing with equality saturation's **congruence closure**, term rewriting and extraction. Extensional relational facts, functional dependencies and equality classes must be modeled distinctly. The paper demonstrates pointer-analysis and floating-point rewrite applications. It does not assert that every Datalog join or side-effecting program admits an equality-preserving Boolean rewrite.

Current egglog 3.0 has a read-only **proof reconstruction** API. Its `ProofStore` is a hash-consed arena sharing subproofs via `ProofId`; proofs justify *equality propositions between terms*. That alone is not a proof that a physical Lance write succeeded.

## Hypothetical transfer

Cold, version-pinned optimizer outside the hot mask-RISC path:
`relalg/R2IL terms -> sorted/canonicalized predicates -> e-class saturation -> extract minimal witnessed DAG -> palette8 opcodes -> QR256 folds`.

Metric should combine bindings, source reads, mask materializations, dirty propagation and replay cost. A shorter AST can perform worse if extraction destroys co-addressing or induces repeated preparation.

Small motivating equality: `a = 2*b; b = 2*c; z = 2*a`, hence `z = 8*c` under exact integer arithmetic. Under saturating u8 arithmetic or f64 reassociation this needs a separate law or a refusal. Cyclic equations require conflict/termination handling; avoid unbounded saturation.

## Falsifiers / test path E

- **E1, substitution:** Prove `z == 8*c` with exact integer constants and capture a replayable DAG. Remove a premise; the proof must fail or be incomplete.
- **E2, million requested applications:** 256 templates × 4,096 focus contexts = 1,048,576 applications. Measure input program records, shared e-nodes/e-classes, extracted program op count, certificate bytes, planner time, memory, validation time, and end-to-end execution. Compare against an intentionally nonsharing workload; no universal small-certificate promise.
- **E3, typed laws:** Existential `OR` versus parity `XOR` and set versus bag COUNT must not unify. Duplicate derivations give a mandatory counterexample.
- **E4, proof/witness:** Check extracted expression equivalence and separately validate BEFORE/AFTER by independent QR scalar oracle; stale coordinate/palette generation refuses.
- **E5, termination:** Recursive cyclic term rules obey fuel/node limits; no infinite expansion; compare bound-limited saturation to ordinary relalg normalization.
- **Silence twin:** An algebraically redundant rewrite changes neither result nor committed dirty bit.

## 2026-10-22 addendum: PLDI 2023 primary-paper harvest and mathematical compiler seam

**Additional primary text checked:** [Zhang et al., PLDI 2023 author PDF](https://ztatlock.net/pubs/2023-pldi-egglog/2023-pldi-egglog.pdf), 25 pages, DOI [10.1145/3591239](https://doi.org/10.1145/3591239). The author's PDF identifies CC BY 4.0; the points below paraphrase §§2–6. These are **paper claims** and **LG hypotheses** respectively, not a fresh egglog version/API audit.

### Paper ideas, in their dependency order

1. **Fixpoint engine plus equality:** Datalog derives facts incrementally, while e-graphs store congruence classes of terms. egglog combines *both*: uninterpreted functions, explicit `union` equivalence, rules and queryable relational facts. Equality between terms is not the same thing as identity between physical source rows.
2. **Functional database and conflict repair (§§3, 5):** Functions are maps from argument tuples to one result. `:merge` resolves an existing output versus a newly derived one. In a shortest-path example the merger is `min`, while equality-style merges may union e-classes. The core well-behaved lattice subset has stronger guarantees than arbitrary user-defined merge expressions. **Do not conflate** this with SQL `MERGE`, bag union, write authorization, or CE64 evidence revision.
3. **Congruence rebuilding (§5):** Unioning arguments can make previously distinct function keys identical. Rebuilding canonicalizes keys and repeats conflict repair until congruence is restored. The mechanism is not merely a dictionary of manually normalized strings.
4. **Semi-naive deltas (§4):** Iterations work from a differential fact database, deriving newly enabled rules instead of rediscovering all earlier facts. The key reuse lesson for LG is to distinguish `candidate`, `actual changed` and `committed` deltas; egglog's logical delta is *not* an acknowledgement of a Lance write.
5. **Analysis-guarded arithmetic (§6):** The floating-point/Herbie example tests whether transformations are safe in their admitted numeric domain instead of applying an unconstrained algebraic identity. Across 289 Herbie benchmarks the sound-analysis system is reported faster overall (73.91 versus 81.91 minutes), but more accurate on 104 and less accurate on 135 compared to the unsound baseline. There is **no universal accuracy dominance**.
6. **Case-study speed is substrate-specific (§6):** The paper reports a 4.96× improvement in its Steensgaard-style pointer-analysis reimplementation versus Soufflé; this is not an across-the-board Datalog, PathMap or LG planner speedup.

### Decision: mathematical compiler, not a Datalog competitor

The useful abstraction is an **offline equivalence and lawful rewrite compiler** that lowers into the *existing* R2IL SIMD polyfill:

```text
typed high-level intent / relalg
  -> canonical terms and checked rewrite-law domain
  -> egglog saturation (bounded, delta-driven, optional proof DAG)
  -> effect-safe extraction / source-generation guards
  -> R2IL FoldDialect procedure
  -> Quack / mask-risc execute_into
  -> independent scalar oracle and, separately, commit if authorized
```

egglog owns *equivalence exploration*, not relational storage, SQL NULL representation, SIMD execution, or source-version authority. **Make the legal domain part of the rule ID:** Bool2 set, SQL K3 with validity, exact integer, float with explicit error policy, Bag/Distinct and side-effect classes must remain separate.

**Example rule boundary:** `And(P, All) = P` is legal for a co-addressed typed Boolean plane. `UNION ALL(R,R) = R` is false for bags; `UNKNOWN = valid FALSE` is false for SQL 3VL. `a=2*b; b=2*c; z=2*a` can give `z=8*c` in exact integer arithmetic but not under arbitrary overflow, saturation, or f64 reassociation. A successful `union` of *terms* must never be reinterpreted as an authorized union of NodeGuids or external identities.

**One minimal falsifier:** compare one 256-rule shared-core compilation versus direct relalg normalization over pinned 256-slot frames. Require (i) identical typed outputs for NULL/FALSE/UNKNOWN and Bag/Distinct adversaries, (ii) no extra source reads across a stale/mismatched binding, (iii) bounded e-graph/rewrite fuel and deterministic extraction, (iv) total measured time after compilation + binding + verification, and (v) an independent scalar oracle. The nonsharing control must be reported alongside the shared case.
