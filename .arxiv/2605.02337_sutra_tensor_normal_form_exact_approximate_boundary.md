## Source-grounded excerpts (paraphrased)

**S1. Symbolic source -> tensor dataflow (§1.1, §4).** Sutra is a typed functional language with VSA operators (`bind`, `unbind`, `bundle`, similarity), polynomial three-valued logic and recurrent loop cells. Its compiler parses `.su`, inlines definitions, performs beta reduction and algebraic simplification (the paper names egglog), then emits PyTorch operations. Literals, role rotations and synthetic-axis slots are resolved at compile time; the intended runtime body is branch-free tensor dataflow. **Qualification:** the paper explicitly calls the composed-XOR-to-`-ab` pattern rewrite **queued, not yet shipped** (§1.1); an example of a desired canonical simplification is not evidence that the compiler already performs it.

**S2. Kleene truth table and smooth extension (§1.1).** Truth codes are `F=-1`, `U=0`, `T=+1`. The paper gives the Lagrange polynomial extensions

```text
AND(a,b) = (a + b + a*b - a*a - b*b + a*a*b*b) / 2
OR(a,b)  = (a + b - a*b + a*a + b*b - a*a*b*b) / 2
NOT(a)   = -a
XOR(a,b) = -a*b    [direct interpolant on the 3x3 truth grid]
```

On the **nine discrete inputs** for AND/OR these implement strong Kleene min/max; between those points they are smooth polynomials, not the same operators as continuous min/max.

**S3. VSA capacity is substrate- and depth-sensitive (§3.1, §3.1.1).** For one bundled bind/unbind retrieval with `k=8`, rotation binding reportedly reaches **100%** on all four frozen embedding substrates (three text encoders and ESM-2 protein embeddings); Hadamard binding often fares much worse. At `k=48`, rotation decoding ranges from **42.3% to 93.3%** across those substrates. Under **repeated nested bundling** (bundle width 4; 20 trials), raw decode at chain length 4 falls to **20%/5%/5%** on the three text encoders, and by length 8 falls near chance. Adding a hard codebook snap between operations is reported to worsen the multi-step results. This is **not** evidence that unrestricted nested VSA structures preserve exact relations.

**S4. Uniform vectors carry an explicit synthetic layout (§3.2).** Values use `[semantic | synthetic]`, with dedicated synthetic axes for real/imaginary components, truth, character, loop completion and slot pairs. The 768+100 dimensional example reserves axes at compile time. Semantic binding rotations leave synthetic axes unchanged. Thus the apparent absence of runtime string/slot lookups is partly a **precomputed addressing decision**, not magic elimination of identity or index management.

**S5. Recurrent control flow still has a boundary (§3.3).** Tail-recursive bodies become fixed-width soft-halt RNN cells. Halt detection and state freezing are tensor-side; a thin Python driver still checks a scalar and ends the tick loop. The paper distinguishes O(1) inference *state width with respect to recursion depth* from **O(number of ticks)** autograd tape during training. A branch-free **cell** is not an entirely branch-free **program**.

**S6. Trainability is shown; generalization is not established (§3.6).** Reported prototype training uses **992 labeled words, 20 classes** and a fixed fuzzy rule graph with 19 nested ANDs: accuracy rises from **4% to 95%** within 50 epochs and remains there at 300; prototype gradients are nonzero. The trainable vectors change while symbolic source remains fixed. The cited experiment is a classification/training demonstration, **not** an independently evaluated test of held-out systematic compositional reasoning.

## The decisive counterexample: exact on a grid != a valid continuous AND

The interpolant matches Kleene AND at `-1, 0, +1`, but not monotonicity away from that grid:

```text
AND(0.5, 0) = 0.125
AND(1.0, 0) = 0
```

Increasing the first operand reduces the result. Therefore do **not** describe this polynomial as a continuous Gödel t-norm or silently reuse it as monotone epistemic confidence, CE64 evidence, a provenance semiring, or an access-control policy operator. It is a differentiable *extension of a discrete truth table*. Test boundedness, monotonicity, associative rewrites and error propagation in any proposed continuous domain **separately**. Algebraic equivalence on the discrete grid does not license continuous-domain rewrites under gradient descent.

Dense role rotations also impose a measurable cost: one `768 x 768` `f32` matrix occupies **2.25 MiB**, i.e. 225 MiB for 100 independent role matrices before other data. A precomputed matrix avoids runtime *construction*, not memory bandwidth or `O(d^2)` dense matvec work. Structured permutation/rotation families deserve separate capacity-versus-cost probes.

## Hypothetical transfer to lance-graph (not a proposal to replace exact relations)

**Interesting shared pattern:** move symbol-name resolution, binding and rewrite work *out of the hot loop*. Sutra materializes role rotations and codebooks; LG can bind NodeGuid / ValueId / D-KEY16 coordinates and local index registers, then run mask-risc/Quack folds on stable populations.

**Keep an explicit boundary:**

```text
MeTTa / R2IL / relalg source
             |
      typed, versioned IR
             |
    legal rewrite + binding
          /       \
 exact discrete    continuous approximation
 mask / LUT /      tensor / VSA / autograd
 local-index       (only if semantically licensed)
          \       /
     evidence/provenance contract
```

This diagram is an **LG research hypothesis**, not a capability established by Sutra or already shipped in LG. Any `egglog` equality has to be tagged with its validity domain; do not promote a polynomial fuzzy identity into exact Kleene or probabilistic equivalence without proof. A local-index register is an address mapping; VSA rotation is a lossy-superposition-capable content transform. They are **not interchangeable** just because both bind a role to a value.

Potential beneficiaries: a typed relalg/polyfill backend selector; MORK/MeTTa lowering to bounded folds; comparison of continuous rule-scoring with exact 3-state truth masks. No new opcode, CE64 interpretation, or persistent substrate is justified by this paper alone.

## Falsifiers / small independent probes

1. **F1: Kleene versus continuous.** Exhaust all 9 ordered truth pairs for AND/OR; compare with a scalar strong-Kleene oracle. Then grid-sweep fractional inputs in `[-1,1]`, search monotonicity/associativity/boundedness counterexamples; in particular pin `AND(0.5,0)>AND(1,0)`. **Red:** a planner uses continuous polynomial equality as a valid exact-relation rewrite without a domain proof.
2. **F2: Binding capacity + composition.** Reproduce `k={2,8,16,32,48}` and chain lengths `L={1,2,4,8}` with fixed seeds/codebooks, alongside exact local-register mapping. Count decoding accuracy, false matches, round trips, prewarm time, cache memory and wall time. **Red:** deep VSA decode is treated as identical to exact many-to-many joins.
3. **F3: Rewrite law and shipped optimizer.** Test direct `-a*b` against the composed XOR of the paper on the 3x3 truth grid *and* fractional inputs; examine the compiled trace before asserting an egglog fusion. Record cold compile, warm compile and execution separately. **Red:** compiler aspirations are reported as measured fused-kernel behavior.
4. **F4: Termination / unknown / failure.** Compare Sutra's halted, nonhalting and near-threshold soft-halt cases to bounded fixed-point/R2IL scheduler outcomes. Require separate states for **unfinished**, **false** and **unknown**; a zero-gated output must not be read as a completed negative proof. Measure ticks, tape memory and driver costs.
5. **F5: Exact/approximate routing.** Execute one fixed set of 3-valued rules on exact masks and on polynomial tensors; require exact grid agreement and explicit divergence reports on fractional inputs. Decline ambiguous lowering instead of inserting an implicit confidence threshold.

**Decision:** keep as a source-grounded research bookmark and falsifier list. No semantic parity claim, no optimizer/kernel performance claim, no new implementation authorized. Favor a narrow verified subset and explicit refusal for unsupported transformations.
