# arXiv:2608.00546 — Path invariance and explicit boundaries

Source: https://arxiv.org/abs/2608.00546  
PDF: https://arxiv.org/pdf/2608.00546

## Punchline

A result is stronger when it survives every admissible representation and execution path.

The paper's useful substrate pattern is not "implement QFT renormalization". It is:

1. distinct legal evaluation schemes can converge to one canonical result;
2. singular/degenerate cases become explicit boundary strata rather than hidden exceptional control flow;
3. global failures localize to boundary contributions;
4. a problematic local subgraph can be contracted to a compact local object and global evaluation can continue;
5. disconnected components do not invent a joint anomaly.

For lance-graph this suggests a verification contract:

```text
same semantic operation
        |
        +-- fused fold
        +-- materialized mask -> fold
        +-- Quack -> Program -> fold
        +-- streaming / tiled / batched lowering
        |
        v
same terminal result
```

When those paths disagree, the disagreement should be represented as an explicit, localizable epistemic boundary rather than diluted into a confidence float.

## Takeaways

### T1. Canonical result across distinct evaluation schemes

The paper proves agreement between several mathematically different regularization/evaluation schemes.

Substrate harvest:

```text
semantic state
    -> admissible lowering A
    -> admissible lowering B
    -> admissible lowering C
    -> same terminal state
```

Execution strategy is implementation detail where the semantic contract says it may vary.

This is a stronger invariant than "each implementation passes its own tests".

### T2. Make degeneracy part of the state space

Instead of treating singular configurations as exceptional accidents, the construction explicitly adds boundary strata describing how parameters degenerate.

Substrate harvest:

```text
normal state
normal state
boundary state
normal state
```

not:

```text
normal state
normal state
special-case branch / undefined
```

A missing, contradictory, underdetermined, or collapsed relation should be representable, inspectable, and replayable.

### T3. Preserve nested boundary structure

The boundary construction distinguishes nested degeneracies, not merely a flat set of failures.

Substrate harvest:

```text
S0
└── S1
    └── S2
```

must remain distinguishable from independent failures:

```text
S1   S2
```

Do not flatten structurally different epistemic defects into one scalar uncertainty score.

### T4. Global invariant failure should localize

The paper expresses failure of the desired global condition through explicit boundary contributions.

Substrate harvest:

```text
global invariant failed
        |
        v
smallest responsible population / relation boundary
```

This is a useful interpretation for the 59/60 frontier: detect and localize unresolved structure rather than merely lowering confidence.

### T5. Contract locally, then continue globally

A subgraph contribution can be represented on a contracted graph by replacing the local problematic structure with a compact local object.

Substrate harvest:

```text
population / subgraph
        |
       fold
        |
 compact evidence register
        |
 replace / contract
        |
 continue global evaluation
```

This is directly compatible with CE64-style inter-cycle evidence registers and with avoiding unnecessary intermediate materialization.

### T6. Disconnected components are a null model

Independent/disconnected components do not create a new joint anomaly.

Substrate harvest:

If A and B have no relation, merely processing them in the same batch, tile, tenant, or scheduler window must not create evidence connecting them.

That is an important guardrail for local plasticity, reinforcement, and future Hebbian/Bayesian layers.

## Architecture laws worth harvesting

```text
R1  REPRESENT BOUNDARIES
    Degenerate or unresolved states are first-class states,
    not exceptional control flow.

R2  LOCALIZE FAILURE
    A failed global invariant identifies the smallest
    responsible population / boundary that can explain it.

R3  CONTRACT THEN CONTINUE
    A resolved local population may collapse into a compact,
    deterministic evidence register without changing externally
    observable semantics.

R4  EXECUTION-SCHEME INVARIANCE
    Equivalent legal lowerings yield the same terminal state.

R5  DISJOINTNESS
    Independent components cannot invent interaction evidence.

R6  NESTED DEGENERACY
    Simultaneous failures preserve inclusion / dependency
    structure instead of flattening into one score.
```

## Testables

### 1. Lowering invariance

For one semantic query, execute through every currently legal lowering:

```text
direct fold
bitmap -> fold
Quack -> Program -> fold
streaming fold
batched / tiled fold
```

Expected:

```text
R_direct == R_bitmap == R_quack == R_stream == R_batch
```

Prefer bit-identical equality wherever the operator is specified as deterministic.

**Falsifier:** changing only the legal execution path changes the terminal semantic result.

---

### 2. Materialization invariance

Compare fused evaluation with explicit intermediate materialization.

```text
A = fold(mask(input))

bitmap = materialize(mask(input))
B = fold(bitmap)
```

Expected:

```text
A == B
```

This should become a regression test around any optimization that avoids the 12/25 ns-style mask/materialization path in favor of the cheaper fold path.

**Falsifier:** avoiding materialization changes semantics.

---

### 3. Reordering / mergeability invariance

For operators explicitly declared reorderable/mergeable, vary tile and partial-reduction order:

```text
A -> B -> C
C -> A -> B
parallel partials
batched partials
```

Expected:

```text
terminal(order_1) == terminal(order_2)
```

Only apply this test where associativity/commutativity/mergeability is part of the operator contract.

**Falsifier:** an operator advertised as mergeable depends on scheduling order.

---

### 4. Boundary localization

Construct a minimal contradictory or underdetermined population, e.g.

```text
A -> B
A -> not-B
```

Expected result is not merely:

```text
confidence = 0.5
```

The runtime should identify the smallest responsible relation/population:

```text
boundary = {e1, e2}
```

or the substrate-native equivalent.

**Falsifier:** the contradiction can only be observed as a global score or global failure.

---

### 5. Contraction conservation

Evaluate a graph both whole and with a local subgraph pre-folded into a compact register.

```text
R_whole = evaluate(G)

r       = fold(S)
G2      = contract(G, S, r)
R_fold  = evaluate(G2)
```

Expected for all observables outside the contracted region:

```text
R_whole == R_fold
```

This is the critical test for treating CE64 or another compact record as a sufficient inter-cycle summary.

**Falsifier:** contraction discards information later required by a legal downstream operation.

---

### 6. Disjointness / no spontaneous interaction

Let

```text
G = A union B
```

with no edge/path/evidence relation between A and B.

Expected:

```text
cross_evidence(A, B) == 0
```

Running A and B in the same tile, batch, tenant, Moore neighborhood, or scheduler epoch must not itself create semantic interaction.

**Falsifier:** execution locality leaks into semantic causality.

---

### 7. Nested-boundary preservation

Construct two cases:

```text
Case A:
S0
└── S1
    └── S2
```

and

```text
Case B:
S0
├── S1
└── S2
```

Expected: the boundary representation distinguishes them.

**Falsifier:** both collapse to the same unordered error/evidence set when downstream reasoning requires the distinction.

This test can tell us whether the 59/60 representation is sufficient by itself or whether it needs a small boundary ordinal / nesting coordinate.

---

### 8. Replay certificate

Persist only the semantic replay ingredients:

```text
input hash
schema/version
0..63 schedule
boundary decisions
contracted registers
terminal
```

Replay must reproduce the terminal exactly:

```text
Replay(trace) == terminal
```

Then repeat through another admissible lowering:

```text
Replay_alternative_legal_lowering(trace) == terminal
```

**Falsifier:** the result depends on hidden execution history that is absent from the replay contract.

## Suggested implementation order

Start with the tests that constrain existing primitives before inventing new representation:

1. **Materialization invariance**
2. **Lowering + reorder invariance**
3. **Contraction conservation**
4. **Boundary localization**
5. **Disjointness**
6. **Nested-boundary preservation**
7. **Replay certificate**

Do not add a new boundary primitive merely because the paper has richer geometry. First try to express the required distinction using existing Local/Via ordinals, masks, fold outputs, CE64/register state, or existing schedule metadata.

Only add representation if a falsifier demonstrates that the existing substrate cannot preserve the required distinction.

## Mapping to the current reasoning bands

A useful working interpretation, not a claim from the paper:

```text
ordinary inference
      |
 masks / folds
      |
      +----------------------+
      | invariant holds      | invariant breaks
      |                      v
      |                boundary detection
      |                      |
      |                    59/60
      |                      |
      |             localize responsible
      |                population
      |                      |
      |                contract / fold
      |                      |
      |             causal interpretation
      |                      |
      +------------------> 61..63
```

The useful distinction is:

- **59/60:** detect/localize an unresolved boundary or missing structural closure.
- **61..63:** assign the surviving epistemic/causal status after admissible resolutions have been applied.

That would make the upper band less like a confidence ladder and more like a replayable statement about what survived attempted resolution.

## One-sentence substrate criterion

> A reasoning result is trusted not because one path produced it, but because every admissible representation and execution path preserves it.

## Non-goals

- Do not import QFT terminology into core APIs unless it names an independently useful substrate concept.
- Do not introduce floating confidence merely to imitate analytic regularization.
- Do not introduce a new graph materialization step to model "boundaries".
- Do not assume all operators are reorderable; the test applies only when the algebraic contract says they are.
- Do not expand 59/60 or 61..63 until a concrete falsifier proves the current representation insufficient.
