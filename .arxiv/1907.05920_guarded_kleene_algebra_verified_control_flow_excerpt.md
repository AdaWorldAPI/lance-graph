# GKAT: prove guarded control-flow rewrites before lowering

**Primary source:** Steffen Smolka, Nate Foster, Justin Hsu, Tobias Kappé, Dexter Kozen, Alexandra Silva, *Guarded Kleene Algebra with Tests: Verification of Uninterpreted Programs in Nearly Linear Time*, POPL 2020, [arXiv:1907.05920v4](https://arxiv.org/abs/1907.05920v4), [PDF](https://arxiv.org/pdf/1907.05920), [DOI](https://doi.org/10.1145/3371129). Source sections: §§2.1–2.4, 3.2, 4.2, 5.2–5.3; particularly Theorem 2.4, Definition 3.4, Proposition 4.2, Algorithm 1, Theorem 5.10, Proposition 5.11.

**Research status (2026-10-21):** PDF-grounded excerpt and hypothetical architecture transfer. No GKAT implementation, benchmark or new production engine claimed or authorized.

## Source-grounded excerpt

**GKAT is a deterministic, predicate-guarded fragment of Kleene Algebra with Tests (KAT).** It retains uninterpreted actions, Boolean assertions, sequential composition, guarded choice (`if b then e else f`) and guarded iteration (`while b do e`), but does **not** retain KAT's unrestricted nondeterministic union or Kleene star (§2.1). This restriction is what makes the equivalence problem tractable.

A GKAT execution is a *guarded string*: alternating Boolean-state observations (atoms) and uninterpreted actions. The semantics has a **determinacy property**: agreeing on observed atoms fixes the actions chosen at corresponding positions (§2.2). Interpreting actions as binary state relations yields a sound and complete relational model (Theorem 2.4). Here “relational” means relations over *program states*, not an automatically complete SQL/relational-algebra optimizer.

The construction is:

1. Translate each GKAT expression to a deterministic guarded Thompson automaton in linear size/time for fixed Boolean alphabet (§4.2, Proposition 4.2).
2. Normalize dead transitions, then decide equivalence through bisimulation of the initial states using a Hopcroft–Karp / union-find check (§5.2–5.3, Algorithm 1).
3. Theorem 5.10: **O(n α(n))** with `n = |e1| + |e2|` **when the set of Boolean atoms is fixed**. Ordinary KAT equivalence is PSPACE-complete. The speedup is a property of this restricted algebra, not of arbitrary rule execution.

**Important limit:** with `k` independent primitive Boolean tests, the set of truth-assignment atoms can have `2^k` members. Proposition 5.11 says equivalence with unfixed atom count is co-NP-hard (and in PSPACE). The authors mention symbolic methods to avoid explicit atom enumeration; the paper does not establish a universally near-linear cost for arbitrarily many predicates.

**Derivatives and loops:** Definition 3.4 defines guarded Brzozowski-like derivatives `D_α(e)` for next-step behavior. The fundamental decomposition (Theorem 3.7) separates immediate success from productive next actions; Lemma 3.9 rewrites loops to a productive form. This is a useful verification vocabulary for *guarded* iterative plans, not a generic guarantee that Datalog recursion terminates.

## Small illustrative law (paper §2.3, Example 2.5)

```text
if b then { p; q } else { q }
    ==
(if b then { p } else { skip }); q
```

In GKAT notation, `(p · q) +_b q ≡ (p +_b 1) · q`. The algebra proves equivalence for uninterpreted actions with the same identities. It does **not** prove that evaluating `q` earlier or later is safe when a physical operator has nonmodeled external effects.

## Hypothetical Lance-graph transfer

**Potential seam:** `lance-graph-contract` owns the canonical single-table Boolean-set algebra and rules (D-RA-2); `lance-graph-relalg` keeps relational lowering/planning; Quack owns physical lowering, not a verified cost model. See [D-RELALG-UNIFIED](../.claude/plans/d-relalg-unified-v1.md). Do not create a competing general AST.

A **cold, opt-in guarded-plan equivalence checker** could validate a limited class of plan rewrites before the resulting operations reach R2IL / mask-risc:

```text
typed guarded logical plan + declared pure action identities
            |
       GKAT translation
            |
    deterministic automata
            |
       bisimulation
            |
    accept/reject rewrite
            |
  relalg/Quack lowering -> mask-risc
```

Possible applications: factor a common pure trailing operation out of branches; eliminate equivalent nested guard structure; compare alternative well-structured loop expressions. egglog may *propose* candidates, while a restricted GKAT checker can validate the **guarded-control-flow component**. This is adjacent to [egglog excerpt](2304.04332_egglog_equality_saturation_datalog_excerpt.md), not evidence that GKAT proves all egglog, arithmetic or relational rewrites.

**Mapping warning:** a GKAT atom is one logical truth assignment; a DR64/DR256 mask is a physical set of selected lanes; a global-to-local register maps coordinates/identities. These have different semantics. A mask may implement a guard after a version-pinned, typed projection, but cannot itself stand in for a GKAT equivalence proof.

**Contract boundary:** physical prefetches, cross-table positional reads, writes, temporal visibility, dirty-bit changes, duplicate multiplicities and null/unknown values require separate operator contracts. In particular, SQL three-valued logic, bag `COUNT`, nonmonotonic negation, arbitrary nondeterministic branching and unconstrained recursive Datalog rules are **outside** the plain GKAT theorem.

## Falsifiers / experiments (proposal only)

- **G1, guarded factoring:** Admit the example above for identical *pure* `q` actions; generate a scalar reference trace set and compare accepted behaviors before and after rewrite. Change one action label or guard polarity; reject.
- **G2, nondeterministic negative:** A genuine “choose either `p` or `q` regardless of guard” must not be silently encoded as GKAT `if` under an invented predicate. Test the determinacy property explicitly.
- **G3, null/bag negative:** SQL `NULL`/unknown and duplicate-sensitive `COUNT` examples must fail translation or require an explicit separately validated typed semantics. Boolean set `OR`, parity `XOR` and bag aggregation must never be conflated.
- **G4, loop productivity:** Compare a small guarded loop with its productive derivative form using a bounded independent trace oracle. Distinguish zero-action success, rejection and nontermination; do not equate a Datalog fixpoint with a `while` loop by naming alone.
- **G5, atom explosion:** Vary the number of independent predicates; count explicit truth-assignment atoms, automaton states, proof time and peak memory. Compare symbolic vs enumerated guard representations. Fail closed at configured resource limits.
- **G6, physical parity:** On a valid rewrite, independently check scalar result, mask-result, input/version witness, source reads, materializations and dirty-bit outcome. GKAT equality is **not** proof of operational side-effect or replay equivalence.
- **G7, amortization is separate:** Benchmark 256 rule templates and 256 hops as different cases, including translation/proof overhead. Measure end-to-end execution and disable-path parity, not merely fewer logical operators.

**Silence twin:** when the guard/action contract is insufficient or the proof overhead dominates, retain the ordinary relalg/Quack path; no speculative mask, no changed result and no asserted speedup.

## Decision boundary

**Research candidate only: D-GKAT (unclaimed).** Start with a documentation/fixture probe, not a new runtime dependency or production verifier. Require a typed action/guard subset, failure-on-unsupported constructs, independent semantics oracle and measurable win before promoting it.

**One-line harvest:** Guarded determinism can make *control-flow* equivalence inexpensive to certify; it does not make arbitrary relational joins, recursive inference or physical execution equivalently cheap.
