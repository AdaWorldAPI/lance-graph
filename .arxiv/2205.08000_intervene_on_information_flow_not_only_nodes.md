# Non-Agency Interventions — Intervene on Information Flow, Not Only Nodes

**Paper:** arXiv:2205.08000  
**Title:** Non-agency interventions for causal mediation in the presence of intermediate confounding  
**Author:** Iván Díaz  
**Source:** https://arxiv.org/abs/2205.08000  
**PDF:** https://arxiv.org/pdf/2205.08000

## Punchline

> **A causal intervention can target the information propagated through an edge, not only replace or delete a node. That makes mechanisms and mediated paths testable without erasing everything the intermediate participates in.**

Díaz develops causal effects based on information-transfer interventions and uses them for mediation/path-specific decomposition, including settings with treatment-induced mediator-outcome confounding.

---

## What the paper actually establishes

Much causal inference is expressed through interventions on variables or nodes.

This paper develops a different intervention family:

    node intervention:
    change X itself

    information-transfer intervention:
    change what X transmits along selected graph edges

These interventions can be useful where a variable is not naturally manipulable and can identify path-specific mechanisms in settings where simpler mediator randomization is problematic.

# Harvest for lance-graph

## H1 — "Remove the beneficiary" is too coarse

If candidate B participates in many relations, deleting B globally mixes several questions.

Prefer:

    mask the hypothesized S -> B -> Y route

while preserving unrelated uses of B.

This asks whether B matters **as the proposed intermediate**.

## H2 — Path ablation maps naturally to masks and folds

The counterfactual need not mutate the graph.

    base population
    AND NOT route_mask
            |
            v
    same fold/replay
            |
            v
    reaction

That is closer to the paper's information-transfer intuition than physical node deletion.

## H3 — Reaction shape can classify mechanism

For candidate B compare:

    global B mask
    S -> B input mask
    B -> Y output mask
    unrelated U -> B mask

The vector of reactions is more informative than one scalar importance score.

## H4 — CUI BONO becomes path hydration

Starting state:

    IndirectUnknown x Related

Candidate generation proposes B.

Evidence then attempts to hydrate:

    S -> B
    B -> Y

If both bindings become grounded, topology may move to IndirectKnown while certification remains unchanged until stronger evidence is earned.

# Testables

## T1 — Intermediate with two jobs

B participates in two mechanisms.

Global deletion affects both. Selected path ablation must affect only the target mechanism.

## T2 — Directional mediation

Mask S->B, then B->Y, then an unrelated edge.

The hypothesized route should produce a coherent directional signature.

## T3 — Immutable canonical graph

Every intervention is represented as an ephemeral overlay/mask and must replay without mutating the base generation.

## T4 — Confounding fixture

Create a case where naive mediator deletion suggests the intended mechanism for the wrong reason.

The path-specific probe must distinguish the targeted information flow.

---

## Guardrail

Information-transfer interventions have formal semantics tied to a causal model.

Arbitrary edge masking is not automatically a valid causal intervention.

For lance-graph:

> **Hydrate the candidate route, then test the route rather than destroying the whole node.**
