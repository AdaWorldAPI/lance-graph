# Falsification — handover, influence, Dubins, optics

Plans for the notes already in this folder. A claim with no failing test is not a plan. Do not add a crate for any of these until the named test exists.

Related: `IMMATERIAL_HANDOVER.md`, `BOUND_COMPUTATION.md`, `HANDOVER_READING.md`.

## Handover

Plan. Keep the rule as a note until PR 1 (`AlgebraLaw`) lands. Then the address is PR 2, and only as `Destination { space, ordinal }` harvested from a CAM ordinal.

Falsify. A stage that is not a named sink writes a population, or a rename of a label changes the ordinal. Either result kills the note. A borrowed address that still carries properties and a wrapped value is a `PSObject`, and the note is false.

## Influence against the Queen

Plan. Do not unify them. Influence is a closing plus a popcount. Queen pathfinding is a lattice edge: exact advance, one free turn, coal for the rest.

Falsify the split. Show a popcount of the board mask that prunes a node whose heading cannot enter the dock, or that refunds coal. If it can, the split is cosmetic. Falsify the Dubins reading. Show a legal Queen move that is not a circle–straight–circle candidate at the current radius, or a Dubins shortest path that is legal when its length is not the current speed. The second is expected. It is why shortest-path Dubins is only the steer.

## Optical computing

Plan. Keep it as a picture of the transform plane. Do not open a hardware track. Do not cite it as a substrate for the fold.

Falsify the usefulness of the picture. Show a fold checksum that survives an analog inner product with no exact ordinal. If none can, the picture stays a picture. Falsify the rejection. Show an exact, generation-checked `u16` handover implemented as an optical path with a DuckDB-matching popcount. Until that exists, optics does not unblock PR 1.

## What not to plan

A Dubins crate. A morphology crate. A lens. A `RouteRef`. A shared `Refuse`. An executing `merge(i64, i64)` trait. Each waits on the falsifier above, or on the PR sequence in `BOUND_COMPUTATION.md`.
