# NSL neighbor-packing fixtures (H1 01a G01-G12, plus marked additions).
# One source of truth: the Python oracle and the Rust tests both read this file.
#
#   fixture <ID> cap=<none|N> undirected=<0|1>
#   seed      <id> <tag> <x>     labeled Example: features id, tag, x
#   unlabeled <id> <tag> <x>     unlabeled Example: same features
#   edge <src> <dst> [<weight>]  one TSV line; the weight text is kept verbatim
#   end
#
# G09 and G10 are properties of the Rust side (stale seal, shared gather) and
# reuse G08's graph; NSL has no counterpart, so the oracle does not run them.

unlabeled B nbr-B 2.0
unlabeled C nbr-C 3.0
