# dr-isa-stream-lab: benchmark of every arm

Generated by `cargo run --release --bin bench_all`. Every result is checked against its oracle before timing and on every timed run.

Host: Granite Rapids VM, 4 vCPU, rustc 1.99.0. lance-graph `7c301f5` + this branch; ndarray `f6c1a07` (AdaWorldAPI/ndarray#414). Single-threaded throughout. This is not certification on dedicated silicon: AMX tile state can corrupt under host contention, which is why every timed result is checked.

The lance-graph gate is ns per operation and µs per batch. Rows in milliseconds fail it and are recorded as findings, not passes.

Host tile tier: `AMX TDPBF16PS`. n = 65536, 16 lanes, 21 warm runs (median).

## Reading

- **The 256 × 256 cube is the whole universe.** One lane or one WHERE mask over 65,536 identities is a single 256 × 256 matrix, and the WHERE rows run over all of it in one call per 16 lanes. The graph's edge relation is identity × identity: 256 × 256 tile pairs, each a 256 × 256 block. The virtual CSR addresses that second level by `(tile_r, tile_c, slot_r, slot_c)`.
- **WHERE (selection about 50% dense).** The strided tile GEMM with A in place is the fastest arm: 172 µs for 16.7M MACs. Copying A first doubles the cost.
- **ndarray `cblas_gemm_bf16bf16f32` is about 20× slower than the strided tile path on the same problem**, although A is the slab itself at pitch = K. `amx_matmul::matmul_bf16_to_f32` copies both operands (`pack_contig`) and calls `bf16_tile_gemm_16x16` per 16×16 tile, which VNNI-packs B and allocates on every call. Before this entry can serve a stream it needs a prepacked or strided-B variant.
- **Graph aggregation.** A block GEMM's cost is set by block area, not by edges. It loses to a scalar CSR loop at about 0.15% fill (degree 8) and wins about 5–6× at 25% fill (degree 64 within the tile).
- **Long-range edges fill the block layout.** One long-range edge per identity grows the block count about 8×. A virtual CSR needs a locality-preserving G2L order.
- **Every graph row is in milliseconds.** None passes the gate.
