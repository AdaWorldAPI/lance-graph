## Claim to falsify
Can a versioned, typed ON × WHEN × DO **logical incidence relation** be subjected to independent Thought-Git ablations, such that counterfactual outcome differences reveal conditional behavioral dependencies *not established by static SPO alone*, while rejecting false dependencies caused by coincidental co-activation?

The 64³ address space (262,144 possible incidence cells; 32 KiB as a hypothetical fully dense Boolean representation) is **not** the 64-thought axis (0 immutable givens + up to 63 speculative slots) and not a deployed tensor. Each cell can reference multiple independently identified methods. Codebook/local ordinals must not masquerade as global identities.

## Non-negotiable semantics
- **Fact vs hypothesis:** source-attested structure, population observation, statistical candidate, model-relative counterfactual effect, logical entailment, and independently checked law are separately labeled.
- **Intervention:** disabling an ON event, changing WHEN, or suppressing DO is not interchangeable. Unknown/unauthorized/side-effectful scenarios may refuse.
- **Identity:** semantic IDs and source revision, typed method/argument signatures, frame/focus/scope, codebook generation, permission/knownness, program and result witnesses are never collapsed into a u6 ordinal.
- **History:** 0 = sealed givens; 1..63 = resident speculative branches. Replay and protected intermediate read requirements survive squash (#1739).
- **Memory:** no forced dense cube; source data stays owner-borrowed; scratch is bounded and intermediate materialization must be costed.
- **No automatic causal law:** A changes B in one replay is a *model-conditioned outcome*, not universal necessity, world causation, or legal compiler rewrite.
- **External effects:** speculative arms create proposals only; no execution of source business actions.
- **Computation:** native first. ONNX is a compatibility/prediction leaf, MLIR is an optional cold export, DialEgg/egglog is cold optimization, not hot execution.
