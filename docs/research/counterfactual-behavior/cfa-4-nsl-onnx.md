# D-CFA-4 — Optional NSL training / ONNX candidate-ranking feedback

**Status: cold research option / falsifier preregistration only.** Depends on [CFA-3](cfa-3-arm-logic.md). Not a requirement for S1–S3; no model trained/exported here, no ONNX runtime imported, no new numerical kernel or learned evidence authority.

## Falsifiable question
Can a model trained on **source-disjoint, replay-witnessed** method/code connectivity propose *useful next ablations* at a lower total cost than deterministic static+ARM+Thought-Git scheduling, without introducing unacceptable false negative risks?

## Shape crossing: never reinterpret incidence as an embedding
- S1 `ON×WHEN×DO`: typed Boolean registrations on source-attested coordinates.
- S2/S3: relation candidates with provenance, conditional signatures, context and counterfactual outcomes.
- Training: per-method or per-episode feature vectors + *explicitly qualified* neighbor edges/labels and independent train/test partitions. Negative/inhibitory/directional/higher-order edges are NOT automatically positive similarity neighbors.
- Neural Structured Learning: graph-based regularization is a training objective over selected edges and model features; it does not infer causal direction for free or validate an admitted dependency.
- ONNX: optional **exported prediction graph**, versioned with feature schema, weights, calibration and source split. Keep it as a leaf/compatibility target. Existing ndarray and D-NAM numeric authority applies if a native execution experiment is separately authorized.
- Feedback: predictions prioritize Thought-Git ablation **questions**, never write factual SPO edges, dispatch business actions, or certify compiler laws.

## Baselines / ablation budget
A: random-but-seeded selection; B: static read/write conflict prioritization; C: ARM support/conditional mutual information heuristic; D: trained structured graph ranking. Use same limited Thought-Git batches and same test corpus. Report performance separately for 1/5/20/63 simultaneous speculative thoughts (or another justified and fixed budget). Measure candidate recall at k, ablations to first true missing dependency, precision/recall per relation kind, calibration, memory, cold training, model load and amortized inference. Compare training cost, not just per-query speed.

## Falsifiers
| ID | Control | Must happen |
|---|---|---|
| N01 | perfect co-occurrence from one shared trigger, no dependency | model ranking cannot become causal fact |
| N02 | `prevents` edge passed as positive NSL similarity | sign/direction mismatch detected; dataset refused or encoded separately |
| N03 | held-out source codebase/classes differ | disclose out-of-distribution failure; no misleading hit rate |
| N04 | duplicate roots in train and test via thought replay | leakage caught and split invalidated |
| N05 | same feature ordinal under different source/schema version | stale fingerprint refuses reuse |
| N06 | unverified or unsupported ONNX op in native lowering | typed refusal / independent ORT conformance only |
| N07 | no recall or cost gain over ARM heuristic at fixed budget | neural arm is dropped/parked |
| N08 | prediction about effectful method | only proposes isolated probe; no real side effect |
| N09 | model confidence 0.99 but ablation contradicts | keep contradictory evidence; no confidence-based overwrite |
| N10 | runtime cannot preserve result tolerance or quantization semantics | explicit mismatch, no `CertifiedMath` claim |

## Owner separation
ARM remains the statistical observer; Thought-Git owns experiment/version receipts; NSL owns *optional training optimization*; ONNX is model graph interchange/conformance; native numerical execution remains ndarray/D-NAM; DT64 only binds identities/candidate references. D-ONNX-INTAKE-0 #1802 is a cold frontend bake-off; not approval for ONNX as native runtime.

## Promotion criteria
Only keep if held-out, source-disjoint ablation scheduling shows enough value relative to source qualification and training+inference costs. No prediction may be promoted as a fact without the corresponding independently checked source or experiment witness. No trained model is a mathematical-law oracle.
