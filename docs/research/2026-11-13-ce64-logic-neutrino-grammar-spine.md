# CE64 logic neutrinos: a left-corner ON × WHEN × DO research spine

**Date:** 2026-11-13. **Status:** RESEARCH SCRATCHPAD. Docs only, all new connections falsifiable hypotheses.
**Context:** This extends, and does not duplicate, the merged [Prime × Rubik/Moore × Haspelmath × NNUE × XLOG mindmap (PR #1917)](2026-11-01-prime-rubik-grammar-consolidated.md) and [Staunen 13-layer map (PR #1915)](../../.claude/research/2026-11-01-staunen-13-layer-cognitive-fabric-scratchpad.md).
**Firewall:** no CE64 bit reinterpretation, new ClassId/recipe/F### word, runtime, ABI, persistence, AI authorization, proven equivalence, or performance claim.

> **Conjecture:** CausalEdge64 plus a declared ClassView could be a small, typed **relation/inference carrier**. An 8-bit *left-corner rule selector* might recognize which generic ON/WHEN/DO shape applies to an observed source construct or world event. The rule's full meaning, operands, state, guard, evidence and effects would remain externally typed. Existing XLOG/Quack/R2IL/F### or the CE64 ISA would handle only **admitted** operations.
>
> **Counter-conjecture:** a nice common graph shape is not a common logic; 8-bit rule selection may fail as soon as binding multiplicity, resource history, unknown truth or ordered side effects matter.

**Conceptual sketch, not a new type or byte layout:**

~~~text
RuleCandidate = (source_site, recipe_family, selector_u8, operand_sorts)
ON            = (observed_syntax_or_event, trigger_contract, source_revision)
WHEN          = (typed_guard, scope, population, frame, resource, evidence_policy)
DO            = (admitted_Fsharp_algebra | CE64_instruction | authorized_action_body)
Observation   = (answer_or_new_state, witness, oracle_result, typed_refusal)
~~~

- **S0**: Ruff/Ore and Kythe-like Codegraph facts capture what source *says*, not that a method has fired.
- **S1**: OGAR owns canonical Class / association / ActionDef identity; ClassView supplies the declared reading, not another storage format.
- **S2**: the u8 only selects a **candidate** inside an already named rule family; it is not an opcode or universal AST.
- **S3**: a guard is typed by row universe, frame, tenant/scope, truth regime, history, and resource budget. An absent witness is not FALSE.
- **S4**: choose an existing native algebra, a separately governed CE64/NAL inference rule, or a lossless host action reference. These are not interchangeable interpreters.
- **S5–S6**: a result is certified only relative to the independent contract and fixture actually checked.
- **S7**: an NNUE-style score may order attempts; it never grants admissibility, changes WORLD givens or upgrades CE64 causality.

### H1: MeTTa and MORK as semantic syntax, not an added executor

[H] The first left-corner of a declaration such as Rails belongs_to or an OGAR relation recipe can select possible *semantic rules*. MeTTa rule syntax and MORK trie indexing are other frontends/physical algorithms for nested expression matching. A shared SPO/SPOG graph shape does not prove semantic equality or equivalent multiset substitutions.

[CODE] [OGAR recipe.rs](https://github.com/AdaWorldAPI/OGAR/blob/main/crates/ogar-vocab/src/recipe.rs) canonicalizes Rails belongs_to and Odoo many2one. [lance-graph-metta](../../crates/lance-graph-metta/src/lib.rs) is still a one-query hand-lowering probe. The MORK [project](https://github.com/trueagi-io/MORK) and [Datafrog](https://github.com/rust-lang/datafrog) are possible **independent** oracles, not production dependencies.

[KILL] A many-to-one FK association implies inheritance, or MeTTa produces four variable substitutions while the proposed mask route silently returns two.

### H2: XLOG, ONNX and F### may already do most of the math

[CODE] F000 positional aliases preserve a shared mathematical word across names. ONNX uses direct ndarray aliases and semantic checks. XLOG's relational core works through Quack/mask-risc, with F100 reserved for XLOG-specific term inspection. The R2IL fold binding explicitly refuses a foreign lens such as F100; no new F### word should be invented to mask that gap.

[REFUSE] XLOG [Cube::join](../../crates/lance-graph-xlog/src/cube.rs) rejects a previous Join node as another join operand. [Quack](../../crates/lance-graph-quack/src/lib.rs) disallows feeding arbitrary newly derived scatter populations into foreign Gather. Shared symbols are not permission to bypass NotASide or the scoped gather ban.

[GATE] Compare a genuinely admitted one-join COUNT/EXISTS and a two-hop composition against independent scalar semantics, demanding the latter refuse if unsupported.

### H3: Haspelmath roles as a pre-filter on packed edges

[CODE] [CE64 orientation](../../crates/causal-edge/src/orientation.rs) has bits **43..45** (Core + seven semantic functions). Quack supports Cmp::MatchU64 over borrowed u64 lanes. Candidate expression:

~~~text
care = 0b111 << 43
pattern = recipient_code << 43
selected(edge) iff ((edge XOR pattern) AND care) == 0
~~~

[H] Role-filtered forward image and backward preimage may lower through already admitted relational operations. Trie/prefix addressing might narrow blocks, but [XLOG wide closure](../../crates/lance-graph-xlog/src/wide.rs) is not automatically a MORK symbolic expression trie.

[REFUSE] **Grammatical case** (Dativ/Akkusativ), **Haspelmath semantic role**, **relation traversal**, **signed NARS inference direction**, and **Epi5 topology** are distinct coordinates. Core also includes the “not oriented” reading. Do not repurpose role bits as six hex-grid headings.

### H4: CE64 + ClassView and a logic Rosetta Stone

[CODE] [CE64 ISA](../../crates/causal-edge/src/isa.rs) implements five instructions: deduction, induction, abduction, revision, synthesis. Other signed i4 encodings, including intervention/counterfactual, fault rather than masquerade as an implemented instruction. [CE64 syllogism](../../crates/causal-edge/src/syllogism.rs) selects one of four shared-term positions by S/O palette equality.

[CODE] [Epi5](../../crates/lance-graph-contract/src/epistemic_state5.rs): 4 topologies × 6 valid certifications = **24 valid of 32 raw**; 8 orientations × 32 raw Epi5 codes = **256 raw combinations**, but only **192 meaningful**. Those noncontiguous 3+5 bits are **not** a new u8 grammar or opcode; correct reading needs ClassView/provenance.

[H] Kythe/Codegraph source relations, OGAR classes, MeTTa terms, NAL beliefs and R2IL method effects could refer to the same *typed relational identity* while deliberately preserving incompatible truth/variable/effect semantics.

[KILL] A Kythe child edge is treated as logical implication, a Narsese frequency/confidence is treated as Boolean proof, or a mixed source revision yields an admitted MethodRef.

### H5: spaCy, AST, Datafrog and NNUE as feature consumers

[H] A spaCy dependency arc and AST parent/child edge may share an **edge intake pattern**, not a universal grammar rule. Datafrog-style incremental joins could oracle-check bounded XLOG results. An NNUE-style sparse feature can be addressed by a source-qualified edge and context, with **external** learned weights and accumulator.

[GATE] Insert and retire one edge, compare incremental numeric accumulator with full rebuild, and make a deliberately duplicate delivery fail. Reweighting may reorder candidate investigation only, never change a lawful exact answer, grant authorization or alter epistemic certification.

### H6: games deliberately break hidden-state assumptions

[H] A common interface could be:

~~~text
ON   = (turn, selected actor, candidate, ruleset revision)
WHEN = (geometry, permissions, history, resource, row universe)
DO   = (ordered changes to board, inventory, rights, observation)
~~~

**Chess:** identical pieces can have different castling or en passant/repetition rights. **Go:** ko/superko can depend on history and ruleset. **Mississippi Queen:** hex heading, speed, river and **six starting coal** govern reachable routes; the first 60-degree turn and speed change by one are free, further turns/changes cost coal. “Left/straight/right” names *immediate headings*, not the full-turn move space. Pin the chosen [rules variant](https://docs.software-challenge.de/spiele/mississippi-queen/regeln) for the oracle.

[KILL] 0 coal and 6 coal admit the same extra-cost maneuver, or two chess positions with different castling rights have identical move masks.

### H7: one byte as a Datalog-shaped left-corner selector

[H] Left-corner recognition of an already harvested AST construct might select candidate OGAR recipe entries **before** typed resolution. This is *not* a new Ruby parser, not an interpreter, not full unification and not the assertion that 256 codes cover all behaviors.

~~~text
observed(site, first_construct)
candidate(site, recipe) :- left_corner(recipe, first_construct)
admit(site, recipe) :- candidate(site, recipe), exact_typing(site, recipe),
                       guard_and_frame_ok(site, recipe), equivalent_native_path(recipe)
~~~

The last line is an **illustrative obligation**, not a deployed Datalog admit function. A low byte only has meaning inside an existing OGAR recipe family, separately from F### lens positions and separately from CE64 fields.

[CODE] [DT64](../../crates/lance-graph-dt64/src/lib.rs) already stores MethodBinding effects **in order** and WHEN as Guard; [R2IL binding](../../crates/lance-graph-r2il/src/binding.rs) currently **refuses guards it cannot execute**. [OGAR lossless DO](https://github.com/AdaWorldAPI/OGAR/blob/main/docs/HIRO-DO-ARM-LIFT.md) points to executable bodies instead of flattening them into one DDL or byte.

[KILL] Same call-chain prefix, incompatible receiver types, different null rules or effect order are prematurely collapsed into one executable method.

## 4. Cross-dialect distinction ledger

~~~mermaid
flowchart LR
  U["u8 candidate"] -. "not identity" .-> R["OGAR recipe u16"]
  R --> CV["ClassView + typed relation"]
  CE["CE64 packed edge"] --> CV
  CE --> ROLE["Orientation 3 bits"]
  CE --> NARS["Inference i4"]
  CE --> EPI["Epi5 5 bits"]
  CV --> GUARD["WHEN + witness"]
  GUARD --> EFFECT["DO selected permitted execution"]
  EFFECT --> O["independent oracle and observation"]
  ROLE -. "not traversal" .-> GUARD
  NARS -. "not truth by tag" .-> GUARD
  EPI -. "not new certification" .-> GUARD
~~~

- **u8 recipe position ≠ u16 RecipeConceptId ≠ F### lens classid ≠ MethodId ≠ CE64 orientation × Epi5 code**.
- **SPOG graph/context ≠ relational FK join ≠ is_a inheritance ≠ part_of containment**.
- **Candidate selection ≠ guard truth ≠ authorization ≠ execution ≠ observed effect ≠ causal proof**.
- **NARS truth, SQL 3VL, MeTTa substitutions and Boolean masks are not exchangeable** without a declared, tested mapping.
- **MORK trie, XLOG sparse block mask and NNUE feature address are not one physical data structure**.
- **CE64 orientation (semantic role), inference mantissa sign, Epi5 topology and spatial heading** may all be called “direction”, but cannot share one byte meaning.

## 5. Minimal discriminatory probe ladder (all proposed, not run)

| Gate | Independent oracle | Positive invariant | Negative arm |
|---|---|---|---|
| **P0: left-corner candidates** | hand-declared scalar candidate/typing table | same prefix may yield several candidates; only fully typed binding admitted | change receiver, class reading, source revision; wrong candidate refuses |
| **P1: CE64 role mask** | scalar bit decode at lengths 0,1,63,64,65,256,257 | Quack MatchU64 selects exactly the intended semantic-role set | mutate role vs mutate Epi5 independently |
| **P2: Rails-to-F000** | ActiveRecord fixture and unrelated Rails corpus | same normalized rule, native F000 parity, no duplicate Rails evaluator | missing concern, retarget association, two-hop call still non-executable |
| **P3: XLOG/Datafrog/MORK** | pinned external implementations, matching exact query sorts | equal set/multiset of substitutions and recursive result | duplicate bindings, unsupported chained join and recursion |
| **P4: rule worlds** | chess legal-move engine, Go ko reference, Mississippi rules fixture | same ON/WHEN/DO interface and different legal masks for hidden-state twins | omit castling rights, ko history or coal |
| **P5: NNUE delta** | full scratch accumulator rebuild | exact numerical add/remove parity under fixed feature dictionary | duplicate update, stale class or revised feature basis |
| **P6: Rosetta round-trip** | independently pinned source language and logic runtimes | declared semantic equivalence preserved for supported subset | non-equivalent truth or effect semantics return typed refusal |

**P0 first:** do not code seven bridges. Construct four pairs of *same surface, different hidden semantic state*: (a) Rails same call prefix but different receiver; (b) CE64 same S/P/O but Recipient versus Core; (c) Mississippi Queen same position/speed/heading with 0 versus 6 coal; (d) same method display name but mismatched source/schema revision. Demonstrate correct candidate set, separate WHEN refusals and no unapproved DO. If the selector cannot preserve those distinctions, **kill the universal selector hypothesis** before performance work.

For each proposed follow-on: save pinned source revision, class reading, exact operand sorts, execution shape, independent oracle, one disable/negative result, and named refuse conditions. No production writes or CE64 certification changes. Cold compiler/oracle and hot fold costs, if measured later, must be kept distinct and follow repository performance doctrine.

## 6. Questions for Fable 5.2 (read-only brainstorming, not change request)

1. Which is the *smallest meaningful logic particle*: CE64 edge, typed relation with witness, or a typed transition? Produce a counterexample for each smaller candidate.
2. Can an 8-bit left-corner rule *within a family* safely select method candidates from Ruff/Ore and OGAR, or is that merely an index into the existing recipe table?
3. Is the Haspelmath role × Epi5 product actually helpful for rule admission, or is it a coincidental 8×32 cardinality that would corrupt semantics if fused?
4. Can one bounded inference be translated among CE64 syllogism, XLOG relational support, MORK match, MeTTa rewrite and NAL, with equal answers **and** multiplicities? Find a case that cannot.
5. Can chess/Go/Mississippi Queen share a typed transition interface without hiding the essential rule-specific state behind an unexamined “context”?
6. What exact ClassView/declaration preserves source identity, role, term topology, evidence and truth family while refusing lossy transcriptions?
7. Could an NNUE-style feature delta rank candidate rules at zero authority, while exact results remain invariant under every ranking permutation?

**Most valuable output:** strongest unexpected lawful commonality, strongest explicit non-equivalence, one minimal gate with a red-first falsifier. No edits, new registries, evaluators, meaning changes or forced convergence.
