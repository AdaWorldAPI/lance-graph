### `mask_shift_morton(src: &[u64], dir: MortonDir, dst: &mut [u64])` — ND :5384 (VERIFIED-IN-CODE)
- Semantics: `dst |= shift_one_cell(src, dir)` — **OR-accumulate, never overwrite** (:5345-5348). Caller zeroes dst for a fresh answer.
- `MortonDir` :5197 = PosQ | NegQ | PosR | NegR — exactly 4 axis directions (q on even address bits, r on odd). Diagonals are NOT variants: "two calls: shift into a scratch buffer along the first axis, then shift that scratch along the second axis into dst" (:5349-5352). So Moore's 4 diagonals cost 2 calls + 1 scratch plane each.
- Field: `src.len()==dst.len()` and that length must be `4^k` (power of two with even log2), else panic (:5385-5391). 64K cells = 1024 words = 4^5 ✓ (256×256 cells).
- No wrap: cells on the far edge in `dir` produce nothing (`inc_word`/`dec_word` return None at axis edge, :5311-5333).
- Span/carry caveat (:5354-5364): "the slice IS the field" — a sub-span gets no carry in or out; equals the restriction of the full-field shift only if the span is Morton-aligned (`lo % len == 0`) AND the source is confined to the span. hex_tenant_mq_probe asserts the alignment (examples/hex_tenant_mq_probe.rs:353).
- Implementation: pass 1 vectorised over `U64x8` (three interior case masks with fixed shifts per direction, tables POS_Q/NEG_Q/POS_R/NEG_R :5262-5288), pass 2 scalar per-word carry into the one neighbouring word (:5424-5450). Shift distance is exactly ONE cell; |Δ|>1 = repeated calls.
- Moore/neighbour helpers: closed search for `moore` in ND src → no Moore helper (ABSENT). Neighbour composition lives in examples: ND examples/hex_tenant_mq_probe.rs `spread_step_shift` :328-403 (6 hex rails: 4 axis + 2 composed diagonals, OR-accumulated = dilation), and LG moore_plasticity_probe tests (below). Parity coverage: ND crates/simd-masking-parity/src/lib.rs:1128 (`0x9xx` group).
- Caller-owned scratch convention: every word writes into caller-provided `dst`/`out_words`; no allocation inside; composed diagonals require a caller-owned `diag_scratch` plane zeroed per use (hex probe :369-381).

## 5. Materialization: C(Δ) = popcount(M ∧ shift(M, Δ)) over a 64K Morton field (1024 words)

What the existing surface requires TODAY (VERIFIED-IN-CODE from the contracts above):
- Axis Δ (|Δ| = one cell, 4 cases): one `mask_shift_morton(M, dir, S)` into a caller-owned, pre-zeroed **full-field dst plane S of 1024 u64 = 8 KiB**, then `mask_ternlog_popcount::<AND2>(M, S, M)` (fused AND+popcount, no further plane). Work: zero S (1024 words) + shift (2 passes) + 1 fused pass.
- Diagonal Δ (4 Moore cases): two calls → needs S AND a second zeroed 8 KiB scratch (shift into T along axis 1, then T into S along axis 2). 16 KiB caller scratch.
- General Δ=(dx,dy): |dx|+|dy| single-cell shifts, ping-ponging two full planes, re-zeroing each time (accumulator semantics).
- Tiling is NOT free: the carry crosses words, and a span shift drops boundary carries unless the span is Morton-aligned and the source confined to it (:5354-5364). With mask-risc's 256-word tile (=4^4, Morton-aligned) a source NOT confined to the tile loses carries — so a tiled shift needs the neighbour tile's edge words. Today nobody does this; the hex probe works on a node span where `state ⊆ tile` by construction.
- mask-risc cannot express any of it: no shift MaskOp (ABSENT, §2). A consumer would call ndarray directly, or precompute S and hand it to mask-risc as a resident `Plane`, where `Count{Ternlog(AND2) over two planes}` lowers to the fused `Ternlog` fold (no scratch).
- Fused shift+AND+popcount: closed search over ND simd_masking_ops.rs (`shift` hits only the Morton section :5174-5450 and unrelated comments) and LG mask-risc/src → **ABSENT**. `mask_ternlog_popcount` fuses Boolean+count but takes three aligned slices; it cannot permute bits.

**Precisely what is missing:** a word-level `Σ_w popcount(M[w] ∧ shift_Δ(M)[w])` that never writes the shifted plane. For one-cell Δ, `shift(M)[w] = interior_dir(M[w]) | carry_dir(M[nb⁻¹(w)])`, so the fused value is computable per word from M[w] and ONE neighbour word — no dst. That is **a new kernel** (or a new facade word, e.g. a `mask_shift_morton_and_popcount`), not a lowering: it cannot be lowered over existing words without materialising S, because no existing word exposes the interior permutation or carry without writing dst. Diagonals/larger Δ compose interior permutations (still per-word + bounded neighbour words) — the kernel would need a Δ parameter beyond `MortonDir`. At the mask-risc layer it would additionally need a new MaskOp/Terminal and a tiled halo (neighbour-tile edge words) to respect the tiled law. (Derived from code; no implementation exists to verify — OPEN.)

## 6. Distinct quantities (do not conflate)

Let M = presence plane, ring R = set of displacements (Moore ring = 8 Δ).
1. **Unique cells within a ring** U(M,R) = popcount( ∪_{Δ∈R} shift(M,Δ) ) (optionally `∧ ¬M`): a set (dilation) count; each cell counted once regardless of how many set neighbours reach it. Computed by OR-ACCUMULATING shifts into one dst then counting — exactly `mask_shift_morton`'s accumulator semantics; the instance in code is ND hex_tenant_mq_probe.rs `spread_step_shift` :328-403 (6 hex rails OR'd into `scratch`, then `& tile`, gated); `popcount_batch_u64` imported there (:58). No Moore-8 instance found.
2. **Displacement-pair autocorrelation** C(Δ) = popcount(M ∧ shift(M,Δ)) = #ordered pairs (p, p+Δ) both set; Σ_{Δ∈R} C(Δ) counts neighbour PAIRS with multiplicity (= 2× undirected edges among set cells), ≠ U. Translation-symmetric: C(Δ)=C(−Δ) in the interior (edges break it: no wrap). **No code computes it** (closed: mask-risc src, ND simd_masking_ops; examples searched for autocorrel → only unrelated hits). Today: shift (§5) + `mask_ternlog_popcount::<AND2>`.
3. **Hamming distance** H(A,B) = popcount(A ⊕ B) between two planes (no displacement). Code: `mask_xor`+`popcount_batch_u64`, or `mask_ternlog_popcount` with an XOR immediate (fused); byte form `ndarray::bitwise::hamming_distance_raw` (ND bitwise.rs:192). Note H(M, shift(M,Δ)) = |M| + |shift(M,Δ)| − 2C(Δ) — related to (2) only through that identity, and |shift(M,Δ)| ≠ |M| at edges.
4. **Weighted measurement** Σ_{p∈mask} w(p): a value-lane reduction under a mask (A2: the mask selects, the weight is a separate lane). Code: `masked_sum_i32` (ND :814) / mask-risc `Terminal::MaskedSumI32`, group variants; per-offset weights as ring templates `Σ_k w_k·popcount(win∧ring_k)` or bit-sliced planes (mexhat arms E/F).
5. **Centre-surround decision** sign/threshold of S(c) = Σ_p w(|p−c|²) with a signed (DoG) kernel, e.g. S(c) ≥ T. A weighted measurement (4) with positive centre / negative surround, read as a DECISION, which admits early exit with exact bounds. Code: mexhat_bucket_probe.rs (arm F splits Pos/Neg planes; arm H `[L,U]` early exit) — row-major, probe-only, not on the Morton substrate. Also the M-matrix certify/abstain pattern in moore_observable_first.rs is the analogous "decide before converged" for the f64 stencil.
