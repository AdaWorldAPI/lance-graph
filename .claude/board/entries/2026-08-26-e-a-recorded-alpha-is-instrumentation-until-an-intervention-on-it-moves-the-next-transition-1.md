## The doctrine

> A recorded alpha is instrumentation until an intervention on it moves the next
> transition, and an intervention off it does not.
>
> A domain-aware causal reasoning trace only if its internal state is
> interventionally load-bearing and its traversal is faithful to the causal graph
> it claims to reason over. **Anything less is instrumentation with good
> typography.**

Two axes, never collapsed: **interventional faithfulness** (does changing the
claimed internal state change the next cognitive transition?) and **causal-graph
faithfulness** (does the trace preserve the actual relations, not merely the
right entities or the final answer?).

## Why this is the workspace's own rule, applied one level in

The probe is exactly the can-fire + can-STAY-SILENT twin from the falsifiability
rule, aimed at introspective state instead of a guard. A claimed alpha that
cannot move the transition is the watchdog that cannot bark; one that moves it
from everywhere is the guard that fires on everything and therefore carries no
information.

## The measured target (the reason this is not hand-wavy)

`contract::dispatch_mode` elects `Domain → DispatchMode` per dispatch —
`Confused→FieldGather`, `Chaotic→Stabilize`, `Complex→Sweep` (contradiction
preserved), `Clear→Saccade`, `Complicated→Sweep`, with `DkPosition::MountStupid`
vetoing `Clear`. Three properties make it the right first target:

1. the transition is **typed and deterministic** — `DispatchMode` IS the "next
   saccade" the probe predicts;
2. the election is **computed per dispatch and never stored**, so an
   intervention cannot be masked by cached state;
3. the silent arm has a **pre-declared expected answer** — the module states it
   reads *"only LOGICAL markers + optional MUL — never qualia"*. Perturbing
   qualia must therefore leave the election unchanged. The null was not invented
   for the probe; the code already committed to it, so F-AIF-2 falsifies a
   documented claim rather than a convenience.

## Two proofs, not one

**replayable ≠ diagnostically complete.** Alpha owes *can replay thought* AND
*can localize where thought went wrong*. A fix that cannot name the earliest
lost stage is not a diagnosis. The steal from the cited memory work is the
**ladder** (landing / saccade / revision / unresolved surprise), never the store
— no resident field is added.

## The evaluation stack, and where it departs

Entity Faithfulness · Relation Faithfulness · **Interventional Faithfulness** ·
**Epistemic Faithfulness** (59–60 topology + 61–63 permission appropriate?) ·
**Counterfactual Necessity** (does removing the mediator damage the explanation
as predicted?). The last three are the departure from the cited literature.

The cited evaluation needs an LLM judge to decide whether prose reflects a graph
element. A receipt — visited `NodeGuid`, traversed `CausalEdge64`,
`ReasoningBand`, `TruthValue`, alpha claim, CF/revision outcome — makes Relation
Faithfulness set arithmetic, and lets it express what textual scoring cannot:
*correct relation wrong epistemic status* / *associative band only* / *causal
band* / *correct mediator, failed counterfactual removal*.

The reported gap in the cited work is the point and the graph-level sibling of a
decorative trace: **"the model knows the nouns" ≠ "the model knows what causes
what."**

## Three banking rules

1. **Falsifier, not a memory subsystem** — a stage-ablation test over receipts
   that already exist.
2. **Topology must earn itself** — a diagnostic graph may be a derived view;
   that traversal improves attribution does NOT confer canonical status. It must
   beat a **shuffled-edge null**, a control the cited work does not supply, so
   it is ours to run. No second canonical graph population.
3. **Tails stay in the test receipt** — a tail/quantile independence test
   changes an edge's *evidence*, never `CausalEdge64`'s *meaning*.

Deliberately NOT imported: the constructive sufficiency/necessity optimizer.
That constructs load-bearing traces; this falsifies that a recorded one already
is. Mixing them makes the test grade its own generator.

## Naming

`Octopus` has **zero occurrences in this workspace** (measured), so it is free
internally. Externally it is crowded, including one collision close in kind
(multi-capability reasoning orchestration), which is worse than a distant one.
Keep Octopus internal, use a descriptor externally. Reservation recorded, not
resolved: **"Chain-of-Thought" may be the wrong genus** — CoT names a linear
textual rationale, while this is a gated graph walk with revision and sanctioned
non-answers; the name buys discoverability and invites the wrong baseline.
