## Research question

Can billions of transient exploratory folds produce a small number of independently checked, reusable
mathematical reasoning primitives? Success would mean that later problems execute those primitives directly
instead of rediscovering them.

The success metric is checked laws that are actually reused, per unit of exploration folds plus cold compile µs.
The consensus probability and the number of agreeing lanes are not success metrics.

## Smallest vertical loop and its staged falsifiers

Every stage needs a pre-registered entry and four tests:
- positive;
- negative;
- silent twin (a non-trivial input on which it must NOT fire);
- disable (the guard removed, test must go red; anchor asserted before patching).

Hot costs are in ns, cold costs in µs, never ms. One additive PR per stage. Lab crates only.

**Tactic set:**
- proposer: RCR #4 (effect → antecedent), or HTD #2;
- adversaries: CR #11 (contradictory premises) and ASC #7 (negation / counterexample search);
- verifier: SPP #30 (two independent paths must agree);
- optional budget pruner: TCP #5.

Each is called by id, never through `select_tactic`.

- **S1 — adversarial counterexample gate. The KILL test asked for: a false rule never enters the catalogue.**
  - Setup: several lanes each emit `TacticProposal`s with candidate rewrites over E1 terms. A bounded
    exhaustive i128 oracle sweep runs BEFORE egglog.
  - PASS: every false candidate yields `Disproved(Counterexample)` and never reaches saturation or the catalogue.
    Every true candidate passes on to egglog.
  - Disable: skip the oracle, and a false rewrite enters.
  - Silent twin: an all-true proposal set yields zero refusals.
- **S2 — independent proof check (E-PROOF).**
  - egglog exports its proof as a portable DAG: premises, rule instances, edges. A checker outside egglog
    replays each step against `AxiomSet`.
  - PASS: the genuine proof checks. Each of five mutations is rejected: a premise, a law, an edge, the axiom
    set, the ABI.
  - Disable: a checker that skips the rule match must go red.
  - Needs an `egglog` fork export. That fork is this session's repo (tasks #72-74), so it is coordinated in
    EXO-50.
- **S3 — lowering validated over the full bounded domain.**
  - E1 R2IL lowering is checked exhaustively over a stated domain (e.g. all i16 inputs, or a symbolic proof).
    `target_abi` is enforced.
  - PASS: zero mismatches, and changing the ABI or an overflow case refuses.
  - Disable: drop the overflow guard, and a wrapping input must mismatch.
- **S4 — reuse on a second fresh binding with zero egglog calls.**
  - The catalogue goes from one slot per key to a key set with a binding witness per frame. An egglog
    invocation counter is added.
  - PASS: binding B2 (new frame, new data) executes the cached recipe with counter = 0 and is equal to the
    oracle. A stale scope, a changed ABI, wrong axioms, or bag-vs-set all refuse.
  - Disable: an ignored binding check lets a stale scope through.
- **S5 — Thought-Git link (joint with CC1).**
  - A proved recipe is referenced from a lane receipt by `ProofRef`. CC1's squash keeps the receipt and
    `ProofRef` and drops the exploratory folds.
  - F5 (a synthesised head covers complementary children) and F6 (correlated copies get no proof authority;
    validity is decided by the S1/S2 oracle and checker) are CC1's, in #1736.
  - Joint check: squash refuses if any child holds an unproved claim that the head would drop.
- **S6 — the honest budget.** Measured separately:
  - hot fold throughput (ns/fold);
  - cold proof discovery + compile (µs);
  - certificate and proof bytes vs raw exploratory trace bytes;
  - cache-hit latency (ns);
  - reuse count across fresh bindings.

  The 64 × 10⁶ × 30 s figure is a target. Unless S6 measures it, it is reported as unattained, and proof
  search is never promised to finish within the budget.
