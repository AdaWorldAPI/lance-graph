# 2026-11-10 — D-DT64-G2L-1: one witnessed translation reused across GEMMs

**Status:** MEASURED (lab). Closes the G2L row of
`dr-dt64-locality-execution-contract.md` from OPEN to measured in the lab.
Stacked on #1992 (needs ndarray#418).

**What.** A selection named in global ids is translated once, under one frame
of the source's DR `MapTable`, into the source's own row order (counted
lookups). The object is bound in the source's space; B is prepared once
through the translation; every run then reads the source's lanes in place
with zero lookups. Cross-space reads without a translation stay refused, and
the translation does not grant Gather (ADMISSION B #1640).

**Result** (one AMX VM, three runs): translate once 68–85 µs (3200 lookups),
prepare B once 37–47 µs, warm run 16–22 µs with 0 lookups; re-translating per
operation 128–166 µs (about 8×).

**Falsifiers:** oracle in global ids only; reorder refuses binding,
translation and operand; stale mapping refused; prepared B bound to its
translation; unknown and repeated ids refused. Four disable runs, each red.

**Governing question:** the location of each selected id is resolved once
per translation; B's per-row identity once per preparation; per operation,
nothing.

**Trap:** a disable run leaves its build behind. The bench reported 254 µs
for preparing B from the last disable run's binary; rebuilt, 37–47 µs.
