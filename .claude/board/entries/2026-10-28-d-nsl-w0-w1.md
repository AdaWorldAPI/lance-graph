# D-NSL-W0W1: NSL neighbor selection against a frozen NSL oracle

**Status:** TEST-PINNED (17 fixtures). Code: `crates/lance-graph-nsl`. Plan: `AdaWorldAPI/neural-structured-learning` `research/2026-10-25/01a`, `07a`, `00a` W0/W1.

## Decision

- DECISION: a standalone zero-dependency crate reproduces NSL `pack_nbrs` neighbor selection. Features are stored once; neighbors are row references in a CSR sorted in NSL order.
- SCOPE: selection and the NL_* record shape only. No graph loss, no `build_graph`, no Lance storage.
- BASIS: the frozen oracle runs unmodified NSL `graph_utils.py` / `pack_nbrs.py` (NSL `056c4ac`, TF 2.21.0) over a shared fixture file. 16 of 17 fixtures match byte for byte. NaN weights are refused, because NSL's order then depends on input order.
- REVISIT WHEN: a consumer needs other feature columns, or the H1 control (HashMap + SoA) or a Cora-scale run is measured.

## Evidence

- Added fixtures beyond H1: G01b (default weight), G03b (equal f32, different f64: f64 decides), G07u (symmetrized), G12c (0.0 vs −0.0: tie, ID decides).
- 11 disables, each red on a named test.
- `neighbors(seed, 16)`: 1–2 ns per seed, release, 20,001 edges. Cold parse ≈ 7,600 µs and freeze ≈ 2,000 µs, reported, not gates.

## Paths evaluated (same day)

- DECISION: ADOPT the label codebook (sorted IDs, rank codes; stable dedup keeps the first of equal weights). Exact parity, cold build halved.
- DECISION: REJECT palette512 (SM9) edge weights as sort keys: top-1 neighbor changes for 7–21% of seeds on build_graph-shaped weights.
- DECISION: REJECT a quantized training-loss distance: every encoding fails below a per-component difference of ~0.01, the converged regime.
- PROBE: SM9 as a storage format for neighbor input features (9-bit 2–4× better than int8; ~1% error at difference 0.05). Needs Codec9 runtime scale, batch encode, and a Cora-scale run first.
- The palette mechanism, measured (all synthetic):
  - The rows above used uniform quantization only.
  - PROBE: Fisher-z i8 weights (FamilyGamma, fitted range). Top-1 changes for 0.6–0.8% of seeds, 9–34× better than SM9. Spending codes near 1 is what helps top-k.
  - REJECT: the palette256 needle as the loss distance. 47–99.8% of close pairs share a centroid and read distance 0.
  - REJECT: the int8 output grid of a TFLM-shaped softmax for NSL KL / JS (17% error even for distant pairs).
  - PROBE, strongest: residual coding, i.e. the seed's codes plus an int8 residual on its own scale. Error stays flat from noise 0.5 to 0.001: 0.02–0.07% for L2, L1 and cosine, 0.2–0.5% for KL and JS.
- Euler-gamma deskew: a Gumbel probability-integral transform in FamilyGamma's 8-byte envelope (mu = mean − EULER_GAMMA·beta). It flattens the codes (+1–2 bits of entropy) but takes resolution from the tail, so top-1 order gets 2–3× worse.
  - REJECT for selection; the quantile ceiling behaves the same.
  - PROBE: z-linear at 9 bits (2 × u9, palette512:palette512, 511 levels). Top-1 changes for 0.3–0.4% of seeds, and the LUT error is 4× below FamilyGamma i8.
  - Rounding halves FamilyGamma's truncation error.
- Oracle: six KL / JS softmax cases added; the existing cases are byte-identical. The reference is gated on TF's f32 cancellation budget (ratio ≤ 0.10); TF's own value sits up to 22k ULP away at small divergences.
- Report: `docs/research/nsl/production-path-evaluation.md`.
