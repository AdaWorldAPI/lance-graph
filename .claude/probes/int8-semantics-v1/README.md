# int8-semantics-v1 — D-TFLP Amendment 6.4 lab probe

Differential evidence on the numerical meaning of 8-bit codes. It compares four arms:
- the TFLite Micro reference kernels;
- ndarray scalar;
- ndarray SIMD (AMX, AVX-512 VNNI, AVX-VNNI, AVX2, NEON, WASM SIMD128);
- an exact reference.

Lab only: no production file is changed. TFLM checkout: `5f64e4ad` (tree identical to `8f6596d`),
the 6.3 baseline library.

| file | role |
|---|---|
| `tflm64.cc` | TFLM oracle. `fx`: SaturatingRoundingDoublingHighMul, RoundingDivideByPOT and MultiplyByQuantizedMultiplier on generated cases. `fc`: the real int8 FULLY_CONNECTED kernel via KernelRunner (per-tensor and per-channel), plus the multipliers/shifts Prepare computes (`FCQ`). Build line in its header. |
| `int8sem/` | Rust crate (ndarray path dep). `gen` writes `fx_cases.txt` / `fc_cases.txt` (deterministic seed). `arms` compares the arms → `arms64.json`. `f9public` overflows the public `matmul_i8_to_i32` in release and debug. `requanttail` covers `requantize_i32_to_i8` tail lengths. Build with `RUSTFLAGS="-C target-cpu=native"` so every x86 tier is reachable. |
| `crossdot/` | int8 dot products of ndarray's per-target paths vs an i64 oracle. Native: `simd_int_ops::dot_i8` and `simd_avx2::dot_i8` on raw bytes and on Codec8-biased bytes. `aarch64-unknown-linux-gnu` under `qemu-aarch64-static`: `simd_neon::dot_i8x16_neon`. `wasm32-wasip1` (+simd128) under node WASI (`runwasi.mjs`): `simd_wasm::wasm32_simd::dot_i8_to_i32_wasm`. Outputs in `crossdot_*.txt`. |
| `fcattr64.py` | Attributes every FC cell where TFLM differs from exact math to a stage → `fcattr64.json`. |
| `tflm_fc.txt`, `arms64.json`, `f9public_*.txt`, `requanttail.txt` | Run outputs. The case files are regenerated by `gen`, deterministically (sha256 prefixes: `fc_cases.txt` 4be0779d37471c09, `fx_cases.txt` d5b033be240d0873, `tflm_fx.txt` 9a88e3f3ff02610a). |

```sh
cd int8sem && RUSTFLAGS="-C target-cpu=native" cargo build --release && cd ..
D=$(mktemp -d); ./int8sem/target/release/gen $D
./tflm64 fx < $D/fx_cases.txt > $D/tflm_fx.txt; ./tflm64 fc < $D/fc_cases.txt > $D/tflm_fc.txt
./int8sem/target/release/arms $D <6.2 artifacts.bin>      # writes $D/arms64.json
uv run fcattr64.py $D fcattr64.json
```
